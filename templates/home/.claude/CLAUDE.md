# Sandbox

You're running in a pen sandbox. Network access is limited to an allowlist. If a request fails with a proxy 403 or `CONNECT tunnel failed`, tell the user which domain was blocked and wait. They can allow it without restarting this session. Don't work around it. Pushing to GitHub isn't possible from here: commit locally, and the user pushes. `.git/config` is read-only here. Errors from `git config`, deleting or renaming a branch, and setting upstream tracking are expected; don't work around them.
